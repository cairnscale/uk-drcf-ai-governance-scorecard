# @cairnscale/uk-drcf-ai-governance-scorecard

Lightweight 12-control readiness scorer mapped to **UK DRCF agentic AI guidance**, **UK GDPR / DUAA 2025**, and **EU AI Act Article 50** transparency rules (legacy marking grace period closes **2 December 2026**).

Interactive local browser tool: [cairnscale.uk/tools/ai-governance-scorecard/](https://cairnscale.uk/tools/ai-governance-scorecard/)  
Implementation guide: [Keeping Business AI Safe & Private (2026 UK Guide)](https://cairnscale.uk/guides/uk-sme-private-ai-drcf-governance/)
